Computer Parts

CPU

The CPU handles instructions and calculations. It is one of the most important parts of a computer.

A faster CPU can help with gaming and other demanding tasks.

GPU

The GPU handles graphics. It is especially important for gaming, video editing, and other graphics-heavy tasks.

Some graphics cards can get pretty expensive.

RAM

RAM holds data that programs are currently using. Having enough RAM helps when running multiple programs.

It is different from storage because it does not keep data when the computer is turned off.

Other Parts

  • The motherboard connects the components.
  • The power supply provides power.
  • An SSD or hard drive stores files.
  • Fans and coolers help keep temperatures down.
